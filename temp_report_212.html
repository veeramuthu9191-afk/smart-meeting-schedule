                                                                           SYNOPSIS

 

The Smart Meeting Schedule and Workflow Management System is a web-based application developed to simplify and improve the coordination of organizational meetings and post-meeting execution. The system helps administrators and managers schedule meetings, verify employee availability, prevent scheduling conflicts, send automated email invitations and reminders, delegate actionable tasks, and monitor task progress.

The system provides separate login facilities for Managers and Employees. Managers can securely log in, create meetings with start and end times, inspect real-time staff availability through an automated conflict detection engine, and send invitations. The system automates reminder notifications by integrating PHPMailer and the Windows Task Scheduler (`schtasks`), sending automated email alerts 1 hour and 10 minutes prior to the scheduled meeting start time.

Employees can log in to view their scheduled meetings, review meeting agendas, receive automated notifications, inspect assigned tasks, and update progress percentages (0% to 100%) as deliverables advance. Following meetings, managers assign specific deliverables with target due dates, bridging the gap between discussion and execution.

The system is developed using HTML, CSS, and JavaScript for the frontend, PHP for server-side processing, and MySQL for relational database management under the XAMPP environment. It reduces manual scheduling overhead, eliminates double-booking errors, ensures high meeting attendance through automated countdown email reminders, and provides transparent workflow tracking.

The system can be further enhanced with video conferencing integration (Zoom / Google Meet API), mobile push notifications, and AI-driven optimal time recommendations. Overall, the Smart Meeting Schedule and Workflow Management System provides a simple, efficient, and user-friendly digital solution for managing organizational meetings and workflows.

                                          CHAPTER 1
                                                           INTRODUCTION

The Smart Meeting Schedule and Workflow Management System is a web-based application developed to simplify and manage organizational meeting coordination and post-meeting execution digitally. The system helps in maintaining employee details, scheduling meetings, detecting schedule clashes, dispatching automated countdown email reminders, delegating post-meeting action deliverables, and monitoring employee progress. It reduces manual administrative work and helps organizational managers coordinate conferences and follow-ups efficiently.

1.1 ABOUT THE PROJECT

The Smart Meeting Schedule and Workflow Management System is a web-based application designed to digitalize the management of meetings and post-meeting workflows. The system provides a centralized platform for managing staff information, meeting scheduling, attendee conflict evaluation, automated reminder notifications, task assignments, and progress tracking.

The system provides separate login facilities for Managers and Employees. Managers can log in using their credentials to create new meetings, specify meeting date and time bounds, view staff availability in real time, and invite participants. The system performs automatic conflict detection so that employees who already have an overlapping meeting are flagged, preventing double-booking.

The system also integrates operating system automation via the Windows Task Scheduler (`schtasks.exe`) and PHPMailer. When a meeting is scheduled and attendees are invited, the system calculates countdown offsets and registers background tasks to dispatch automated email reminders 1 hour and 10 minutes before the meeting commences.

Following a meeting, managers can assign specific action deliverables (tasks) linked directly to the meeting agenda. Employees can view their assigned tasks, receive meeting countdown alerts, and submit iterative milestone progress percentages (0% to 100%) along with status tags (`Pending`, `In Progress`, `Completed`).

Overall, the Smart Meeting Schedule and Workflow Management System helps reduce manual coordination overhead, maintains accurate records, ensures punctual meeting attendance through automated email alerts, and guarantees transparent post-meeting deliverable execution.

1.2 SYSTEM CONFIGURATION

System configuration describes the hardware and software environment required to develop and run the Smart Meeting Schedule and Workflow Management System. The application is developed using PHP and MySQL under the XAMPP environment, with HTML, CSS, and JavaScript for the user interface, PHPMailer for email delivery, and Windows Task Scheduler CLI for background automation.

1.2.3 SOFTWARE DESCRIPTION

PHP:

PHP (Hypertext Preprocessor) is the main server-side programming language used to develop the application. It handles business logic, session management, database interactions via MySQLi, conflict detection queries, execution of Windows `schtasks` commands, and response rendering.

MySQL:

MySQL is the relational database management system used to store manager profiles, employee records, meeting schedules, participant mappings, task delegations, and progress update logs. The database is maintained in the `smart_meeting_db` schema.

 

 

Apache (XAMPP):

Apache HTTP Server is the web server that processes client requests, executes PHP scripts, serves frontend assets, and provides a stable hosting environment.

HTML:

HTML (HyperText Markup Language) is used to create the structure of the web pages, including login portals, meeting creation forms, availability grids, dashboard cards, task delegation tables, and update modals.

CSS:

CSS (Cascading Style Sheets) is used to design and style the web pages. It defines color schemes, card layouts, responsive navigation bars, form inputs, status badges ("Available" vs "Conflict"), and progress bars.

JavaScript:

JavaScript is used to provide client-side interactivity, immediate input validation (ensuring meeting end time is after start time), and dynamic user prompts.

PHPMailer:

PHPMailer is an authenticated SMTP email library used to dispatch formatted HTML invitation emails and automated countdown reminder emails via Google SMTP (`smtp.gmail.com`).

Windows Task Scheduler (`schtasks.exe`):

Windows Task Scheduler is an operating system utility invoked via PHP `exec()` to register automated countdown execution triggers, guaranteeing that reminder emails are sent 1 hour and 10 minutes before meetings even when browsers are closed.

Visual Studio Code:

Visual Studio Code is used as the integrated development environment (IDE) for writing, modifying, and debugging PHP, SQL, HTML, CSS, and JavaScript code files.

Web Browser:

Google Chrome and Microsoft Edge are used to render, interact with, and test the web application through the local Apache server (`http://localhost/`).

 

 

 

 

CHAPTER 2
 SYSTEM STUDY

System Study is the process of examining the existing system and understanding its limitations before developing the proposed system. It helps to identify the operational problems in the current manual method and determine the requirements of the new system.

In this project, the system study focuses on the traditional meeting coordination and post-meeting task management process and the proposed digital solution. It analyzes how meeting scheduling, participant availability, conflict detection, automated reminder emails, and task tracking can be managed efficiently using a web-based application.

The study helps to understand the drawbacks of manual meeting scheduling and the features required to develop a simple, reliable, and organized Smart Meeting Schedule and Workflow Management System.

2.1 EXISTING SYSTEM

2.1.1 DESCRIPTION

In the existing system, meeting scheduling and post-meeting action tracking are managed using manual and disconnected methods. Meeting organizers typically draft broadcast emails or phone calls to ask employees about their availability. Each employee checks their personal calendar and replies asynchronously.

The organizer must manually check the replies to find a common free time slot. Meeting reminders are either sent manually on the day of the meeting or completely forgotten. Furthermore, after meetings conclude, action items are recorded on paper notebooks or personal notes without any centralized tracking mechanism to monitor progress.

The manual approach requires excessive time and effort, leading to scheduling errors, double-booking of busy employees, poor attendance, and lack of follow-up on agreed deliverables.

2.1.2 DRAWBACKS

The major drawbacks of the existing system are:

  • Meeting coordination requires substantial manual effort and time.

  • Double-booking occurs frequently due to lack of automated conflict detection.

  • Manual calendar checks often result in scheduling overlaps and errors.

  • Meeting reminders must be sent manually, leading to missed sessions.

  • Meeting absenteeism increases when countdown reminders are not provided.

  • Post-meeting action items are recorded on paper notes and easily forgotten.

  • No centralized system exists to track employee task progress percentages.

  • Managers lack visibility into whether deliverables are on schedule.

  • Record maintenance and search are time-consuming and difficult.

2.2 PROPOSED SYSTEM

2.2.1 DESCRIPTION

The proposed Smart Meeting Schedule and Workflow Management System is a web-based application designed to digitalize and simplify meeting coordination and post-meeting execution.

The system provides separate Manager Login and Employee Login facilities. Managers can schedule meetings by specifying the title, date, start time, and end time. The system automatically performs conflict detection across all employees, displaying color-coded badges (Green "Available" vs Red "Schedule Conflict") to prevent accidental double-booking.

Upon inviting employees, the system automatically schedules operating system level background tasks via the Windows Task Scheduler. At 1 hour and 10 minutes before the meeting start time, automated HTML reminder emails are dispatched to all invited employees via PHPMailer.

The system also includes post-meeting task management. Managers can assign action deliverables tied directly to specific meetings, and employees can submit milestone progress percentages (0% to 100%) and status updates through their portal. All records are stored in a centralized MySQL database, making retrieval and monitoring seamless.

2.2.2 FEATURES

The major features of the proposed system are:

  • Separate Manager Login and Employee Login portals.

  • Employee registration and secure credential management.

  • Meeting scheduling with date and time validation.

  • Automated time-overlap conflict detection query engine.

  • Real-time employee availability display ("Available" vs "Schedule Conflict").

  • Automated meeting invitation email dispatch via PHPMailer SMTP.

  • Automated 1-Hour countdown reminder email via Windows Task Scheduler.

  • Automated 10-Minute countdown reminder email via Windows Task Scheduler.

  • Post-meeting task allocation linked directly to meeting records.

  • Quantitative employee task progress tracking (0% to 100%).

  • Employee notifications page with real-time countdown badges.

  • Centralized MySQL database storage (`smart_meeting_db`).

  • Input validation, session security, and password encryption.

  • Execution logging in `logs/reminder.log` for auditability.

  • Reduced manual coordination effort and elimination of double-booking.

 

 

 

CHAPTER 3
 SYSTEM DESIGN AND DEVELOPMENT

System Design and Development is the process of planning, designing, and developing the Smart Meeting Schedule and Workflow Management System. The system is designed to manage employee profiles, meeting scheduling, conflict evaluation, automated reminder alerts, and post-meeting task tracking in an efficient manner. The system provides separate login facilities for managers and employees. Managers can create meetings, verify attendee availability, send invites, and allocate deliverables. Employees can review schedules, receive automated notifications, and update deliverable progress. The system is developed using HTML, CSS, JavaScript, PHP, MySQL, and PHPMailer. The design focuses on simplicity, accuracy, security, and timely communication.

3.1 FILE DESIGN

File Design describes the organization and storage of files used in the Smart Meeting Schedule and Workflow Management System. The project contains organized PHP scripts for administrative functions, employee operations, database connection, and background CLI automation.

The main landing page is index.php / signin.php, which handles dual-role login authentication. The database/ folder contains `connection.php` for database connectivity and `smart_meeting_db.sql` for the database schema. The manager/ directory contains files for scheduling meetings, evaluating availability, and delegating tasks. The employee/ directory contains pages for viewing meetings, notifications, and updating tasks. Background automation scripts create_meeting_tasks.php and send_reminder.php reside in the root directory.

The major files used in the system include `signin.php`, `signup.php`, `schedule_meeting.php`, `employee_availability.php`, `send_invite.php`, `create_meeting_tasks.php`, `send_reminder.php`, `create_task.php`, `task_updates.php`, `my_meetings.php`, `notifications.php`, and `update_task.php`. Each file is designed for a specific function, making the system easier to develop, maintain, and modify.

3.2 INPUT DESIGN

Input Design refers to the method of collecting and entering data into the Smart Meeting Schedule and Workflow Management System. The system provides simple and user-friendly input forms so that managers and employees can enter required information easily and accurately.

The login page accepts user email, password, and role selector. The employee registration form collects full name, email, password, phone, and department. The meeting creation form accepts meeting title, date, start time, end time, and description. The availability page accepts employee checkboxes. The task delegation page accepts meeting reference, employee assignee, task title, assigned date, and due date. The progress update form accepts task status and completion percentage (0-100%). Input validation is implemented to ensure data accuracy and prevent invalid inputs.

 

3.3 OUTPUT DESIGN

Output Design describes how processed information is presented to users. The Smart Meeting Schedule and Workflow Management System provides clear and understandable outputs through responsive dashboards, notification cards, availability grids, and automated email templates.

The manager dashboard displays navigation cards for meeting scheduling, employee directory, and task tracking. The employee availability grid renders color-coded badges ("Available" in green and "Schedule Conflict" in red). The employee dashboard displays upcoming meetings and progress cards. Furthermore, automated HTML emails generated by PHPMailer display meeting title, date, time slot, agenda, and countdown urgency alerts (Amber badge for 1 hour, Red badge for 10 minutes).

3.4 DATABASE DESIGN

Database Design is the process of organizing and storing data required by the Smart Meeting Schedule and Workflow Management System. The system uses MySQL as the relational database management system. The database stores manager profiles, employee details, meeting schedules, participant mappings, tasks, and progress updates across 6 core tables:

  • manager: Stores administrator credentials and contact details.

  • employee: Stores staff names, corporate emails, passwords, and departments.

  • meetings: Stores meeting titles, dates, start times, end times, and agendas.

  • meeting_participants: Maps employees to scheduled meetings with status.

  • tasks: Stores post-meeting deliverables linked to meeting IDs and employee assignees.

  • task_updates: Maintains milestone progress percentage logs and status history.

Foreign keys with `ON DELETE CASCADE` ensure referential integrity.

3.5 CODE DESIGN

Code Design describes the structure and organization of the program code used to develop the system. The application uses PHP for server-side processing, HTML for markup, CSS for styling, and JavaScript for client-side interactions.

Parameterized MySQLi prepared statements prevent SQL injection. PHP session variables (`$_SESSION['manager_id']`, `$_SESSION['employee_id']`) enforce role-based access control. Windows `schtasks.exe` is invoked using PHP `exec()` to register background automation. Timezones are standardized to `Asia/Kolkata` for accurate countdown math.

3.6 SYSTEM DEVELOPMENT

System Development is the process of converting the system design into a working web application. The Smart Meeting Schedule and Workflow Management System is developed using PHP, MySQL, Apache, HTML5, CSS3, JavaScript, PHPMailer, and Windows Task Scheduler.

Separate login facilities were developed for managers and employees. The meeting scheduling module was built with date and time validation, followed by the algorithmic conflict detection engine. The automated reminder system was engineered by connecting `create_meeting_tasks.php` with Windows Task Scheduler and `send_reminder.php`. Post-meeting task delegation and progress tracking modules were then developed and integrated.

3.6.1 SYSTEM DESCRIPTION OF MODULES

The system consists of 14 functional modules:

 

  1. Manager Login Module: Provides secure authentication for managers, verifying credentials and initiating manager sessions.

  2. Employee Login Module: Provides separate secure login for employees to access their personalized workspace.

  3. Employee Management Module: Allows managers to register new employees, assign departments, and view the staff directory.

  4. Meeting Scheduling Module: Captures meeting parameters with validation ensuring future dates and start times preceding end times.

  5. Conflict Detection Engine Module: Evaluates overlapping meeting intervals using SQL queries to detect attendee availability.

  6. Employee Availability Module: Displays color-coded badges ("Available" vs "Schedule Conflict") to assist managers during selection.

  7. Participant Invitation Module: Stores attendee mappings in `meeting_participants` and sends initial HTML invitation emails via PHPMailer.

  8. Windows Task Scheduler CLI Module: Automatically registers background execution tasks in Windows Task Scheduler using `schtasks /Create`.

  9. Automated 1-Hour Reminder Module: Dispatches automated email alerts 1 hour before meeting start time to all invited participants.

  10. Automated 10-Minute Reminder Module: Dispatches urgent countdown email alerts 10 minutes before meeting start time.

  11. Post-Meeting Task Delegation Module: Enables managers to create deliverables linked to meeting IDs with assignee and deadline.

  12. Task Progress Tracking Module: Allows employees to submit milestone completion percentages (0-100%) and operational status.

  13. Employee Notifications Module: Displays in-portal notification cards with live countdown tags for upcoming meetings.

  14. Error Handling & Logging Module: Handles invalid inputs, session violations, and records reminder dispatch history in `logs/reminder.log`.

 

 

 

 

 

CHAPTER 4
 SYSTEM TESTING AND IMPLEMENTATION

4.1 System Testing

System testing is performed to verify that the different functions of the Smart Meeting Schedule and Workflow Management System work correctly according to their intended purpose. Each major function is tested using valid and invalid inputs, and the system response is observed.

The following modules were tested in the project:

Manager Login Testing

The Manager Login module was tested using valid and invalid email and password combinations.

  • Valid manager credentials → Manager Dashboard is displayed.

  • Invalid password or unregistered email → Login Failed error message is displayed.

  • Empty login inputs → Form validation prevents submission.

Employee Login Testing

The Employee Login module was tested in the same manner.

  • Valid employee credentials → Employee Dashboard is displayed.

  • Invalid credentials → Login Failed message is displayed.

  • An employee account cannot access manager pages → Access denied and redirected.

Meeting Scheduling Testing

The Meeting Scheduling module was tested by entering various meeting parameters.

  • Valid future date and time (Start < End) → Meeting is successfully stored.

  • Past date selected → System displays "Past date cannot be scheduled".

  • End time earlier than start time → System displays "End time must be later than start time".

  • Empty required fields → System prompts user to fill all required fields.

Conflict Detection Testing

The Conflict Detection function was tested using overlapping meeting schedules.

  • Employee has no meeting during selected time → Green "Available" badge is displayed and checkbox is enabled.

  • Employee has overlapping meeting on same date and time → Red "Schedule Conflict" badge is displayed and checkbox is disabled.

  • Prevented double-booking → Accidental conflicting invitations are blocked.

Invitation Email Dispatch Testing

The Invitation module was tested by selecting employees and sending invitations.

  • Selected employees → Participant rows saved in `meeting_participants`.

  • PHPMailer SMTP connection → HTML invitation email delivered to attendee inbox.

  • No employees selected → System displays "No Employee Selected" warning.

Automated 1-Hour Reminder Testing

The 1-Hour Reminder function was tested using the Windows Task Scheduler CLI.

  • Meeting scheduled in future → Windows Task `SmartMeeting__1Hour` created at meeting time minus 1 hour.

  • Task execution time reached → Windows triggers `send_reminder.php`.

  • PHPMailer dispatches reminder → 1-Hour reminder email delivered with Amber urgency badge.

  • Execution record → Success entry logged in `logs/reminder.log`.

Automated 10-Minute Reminder Testing

The 10-Minute Reminder function was tested in the same manner.

  • Meeting scheduled in future → Windows Task `SmartMeeting__10Minutes` created at meeting time minus 10 minutes.

  • Task execution time reached → Windows triggers `send_reminder.php`.

  • PHPMailer dispatches reminder → 10-Minute urgent reminder email delivered with Red alert badge.

  • Execution record → Success entry logged in `logs/reminder.log`.

Task Delegation Testing

The Task Delegation module was tested by assigning deliverables to attendees.

  • Valid meeting ID, employee ID, and due date → Task record successfully created in `tasks`.

  • Due date earlier than assigned date → Validation blocks submission.

  • Assigned task → Displayed in employee's task list.

Task Progress Update Testing

The Task Progress module was tested by submitting milestone updates.

  • Valid progress percentage (e.g., 75%) → Progress updated in `tasks` table.

  • Milestone record → Snapshot logged in `task_updates` for auditability.

  • Progress 100% selected → Status changes to "Completed".

Success and Error Message Testing

Success and error message handling was tested for various operations.

  • Successful meeting schedule → Success alert displayed, redirected to availability.

  • Successful invite dispatch → Confirmation message displayed.

  • Invalid login → Error message displayed.

  • Direct unauthorized URL access → Session validator intercepts and redirects to login.

The main purpose of the system is to provide a digital method for scheduling meetings, detecting schedule clashes, dispatching automated countdown email reminders, and tracking post-meeting deliverables.

The system provides separate Manager Login and Employee Login facilities. Managers can securely log in, create meetings, and check participant availability in real time. The conflict detection query prevents double-booking by disabling employees who have overlapping commitments.

The system automates reminder notifications by connecting the Windows Task Scheduler (`schtasks.exe`) with PHPMailer. It automatically registers tasks to dispatch countdown reminder emails 1 hour and 10 minutes prior to meeting start times, ensuring punctuality and high attendance.

The post-meeting task management module allows managers to delegate specific deliverables linked to meeting records. Employees can update milestone progress percentages (0% to 100%) and operational status (`Pending`, `In Progress`, `Completed`), providing full visibility into deliverable completion.

The application is developed using PHP and MySQL, with HTML, CSS, and JavaScript used for the user interface, and PHPMailer for email delivery. The main database tables include `manager`, `employee`, `meetings`, `meeting_participants`, `tasks`, and `task_updates`. Input validation, session security, password encryption, and execution logging in `logs/reminder.log` are implemented to improve system security and reliability.

In conclusion, the Smart Meeting Schedule and Workflow Management System provides a centralized and user-friendly solution for managing organizational meetings and workflows. It reduces manual work, eliminates scheduling conflicts, ensures timely attendance through automated email reminders, and bridges the gap between meeting discussions and deliverable execution. The system demonstrates how a web-based application can make organizational meeting management more organized, efficient, and easier to maintain.
